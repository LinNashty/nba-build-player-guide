# 打造我的传奇球星｜全方位攻略

基于游戏当前公开前端源码整理的中文攻略工具站。数据核验时间：2026 年 8 月 21 日。

## 内容

- 五位置 13 项属性无冲突最优组合
- 30 支球队 × 五位置的临场选择建议
- 五位置 × 13 项属性前 20 榜单，可展开第 21—30 名
- 112 条当前有效剧情事件的按位置、按目标推荐
- 最有价值球员、最佳防守球员、最佳阵容及胜率逻辑
- 历史地位档位与 100 个档案称号条件
- 当前版本与 2026 年 7 月 20 日旧快照的差异

## 本地运行

```bash
pnpm install
pnpm run dev
```

## 数据更新

原始研究文件位于 `research/current-2026-08-21/`，可复现提取脚本为：

```bash
node scripts/extract-game-data.mjs
```

生成结果写入 `app/data/guide-data.json` 与 `app/data/guide-summary.json`。

## 验证

```bash
pnpm run lint
pnpm run build
```

游戏版本更新后，数值、名单和规则均可能变化。本站不将随机生成属性的 2026 届生涯新秀混入静态建球排行榜。
